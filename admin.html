📝 Lecture Notes Management

Har lecture ke neeche alag notes attach kar sakte hain. Chapter Notes aur Lecture Notes independent hain—ek add karne se doosra zaroori nahi hota. PDF Google Drive link se use hoti hai; Supabase Storage future option hai.

  1. “Open Lecture Notes Form” dabayein.
  2. Chapter select karein, phir Notes location mein us lecture ko select karein.
  3. “Yes, add notes” select karke title aur link save karein.

Agar lecture ke notes nahi dene, to is section mein kuch save karna zaroori nahi. Chapter Notes alag section se manage hote hain.
